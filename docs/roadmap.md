# Roadmap

## Current Foundation

Rebuild Goal 001 establishes package metadata, reproducible environment support,
and the design contract. It stops before physiology and retains zero generated
evidence.

## Ordered Model Layers

1. Implement and interrogate the irreducible controlled core specified in
   `model-specification.md`.
2. Add activity expenditure.
3. Add dynamic body mass.
4. Add protein.
5. Add water.
6. Add thermoregulation.
7. Add plants.
8. Add spatial foraging.
9. Add coupling between established subsystems.

Each layer requires a separately approved small goal with one principal
question, one subsystem, compact predeclared outputs, proportionate tests, and
an explicit stop. The order is directional, not automatic authorization:
results must be discussed before the next layer begins.

Legacy features are not migration tasks. `BWBrook/herbivoreTTR-legacy` at
`legacy-final-2026-07-16` is historical evidence only; its pre-freeze scientific
baseline is `abf68b691b4e30020625d1871dcabe56a5926bc1`.
