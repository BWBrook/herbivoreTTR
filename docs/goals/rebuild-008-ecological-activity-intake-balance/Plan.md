## Goal

Establish a three-fixture, evidence-only ecological reference chain that
separates prescribed routine-activity cost from added prescribed intake and
stops before intake feasibility or behavior.

## Architecture

Compose all fixtures explicitly through the accepted food, activity, and
reference-cycle public functions. Add no production code. Keep scenario
definitions in focused test and experiment clients, validate paired
counterfactuals from returned ledgers, and publish only ignored review aids.

## Global Constraints

- R only; base-R evidence scripts and existing package dependencies.
- Fixed one-hour intervals on integer `hour_of_day = 0:23`.
- Activity and intake are prescribed inputs, not feedback or behavior.
- Active/intake hours are `0:7` and `16:23`; rest hours are `8:15`.
- Activity rate is `50 kJ h^-1` in active hours.
- Baseline and unbalanced intake are `150 kJ h^-1`; balanced intake is
  `200 kJ h^-1` in active hours.
- No production API, schema, variable dictionary, dependency, or caller change.
- Generated review outputs remain ignored and uncommitted.
- One focused repair pass only for material defects.
- Goal 008 implementation remains uncommitted until separately authorized.
